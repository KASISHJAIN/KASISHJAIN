# 💫 About Me

I'm a Computer Engineering student at **The University of Texas at Dallas** focused on **embedded systems and hardware/software integration**.

I build hands-on projects across embedded systems, computer vision, and applied AI using **C/C++, Python, ESP32/Arduino, sensors, and computer vision tools**. I'm especially interested in building reliable systems where hardware constraints directly shape software design.

🔭 Currently working on
Embedded systems, computer vision, and hardware/software projects through coursework, hackathons, and independent builds.

🤝 Looking to collaborate on
Embedded systems, robotics, computer vision, and hardware-focused projects that connect software with the physical world.

📚 Currently learning
C++, digital systems, embedded design, low-level programming, and reliable system architecture.
