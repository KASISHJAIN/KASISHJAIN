# 🚀 Featured Work

### [beat-the-shutdown](https://github.com/KASISHJAIN/beat-the-shutdown) · Honorable Mention, EOG Resources — HackUTD 2026
An operator console for water-facility telemetry that detects pump failures, pipeline leaks, and worn pumps, counts down to each tank's shutdown limit, and recommends the cheapest response — trucks, well shut-ins, a mix, or accepting the trip — while failures across a system share the same truck fleet. Includes a live ESP32-S3 hardware twin and an agent-written shift handoff.
`Python` · `ESP32-S3` · `agent tooling`

### [Vision-Based-Secure-Control-Panel](https://github.com/KASISHJAIN/Vision-Based-Secure-Control-Panel)
A gesture-controlled security panel that replaces physical inputs with intentional hand gestures. Computer vision handles perception, but every safety-critical decision is enforced in state machine logic on the Arduino — so a misread gesture can't put the system in an unsafe state.
`Python` · `OpenCV` · `MediaPipe` · `Arduino`

### [BrailLearn](https://github.com/KASISHJAIN/BrailLearn)
A wearable glove for visually impaired users that converts tactile finger movements into real-time digital text.
`JavaScript` · `sensors` · `embedded`
